## About Lumina Executor

Lumina Executor is a Windows desktop tool for Roblox users working with Lua and Luau scripts. Its small-footprint interface brings script loading, organization, and execution together with a built-in hub for accessing script collections.

Designed around Roblox scripting on Windows 10 and Windows 11, the project includes auto updating, debugger support, saved scripts, and multi-instance functionality. It provides a practical alternative for users looking for a focused executor without an unnecessarily large desktop application.
